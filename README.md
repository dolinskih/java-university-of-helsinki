# Java Programming - University of Helsinki (MOOC.fi)

This repository contains my solutions to the exercises from the **Java Programming** course provided by the University of Helsinki.

The goal of this project is to build a foundation in Core Java and object-oriented programming (OOP) before advancing to the Spring Boot ecosystem.

## Course Overview & Topis Covered

The course is split into two main sections:
* **Java Programming I:** Variables, conditional statements, loops, lists, arrays, and introduction to Object-Oriented Programming (OOP).
* **Java Programming II:** Advanced OOP concepts (inheritance, polymorphism, interfaces), Java Collections Framework, Stream API, Lambda expressions, and exception handling.

## Tech Stack & Tools
* **Language:** Java
* **IDE:** Microsoft Visual Studio Code
* **Testing:** TMC (Test My Code) plugin for automated verification

## Repository Structure
The repository is organized by course parts:
* `/tmcdata/mooc-java-programming-i` - Course I: Fundamentals of Java & Intro to OOP
* `/tmcdata/mooc-java-programming-ii` - Course II: Advanced OOP, Collections, and Streams
